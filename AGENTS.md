# ai-sdk-provider-codex-cli

This repository is the Backspace fork of `ben-vargas/ai-sdk-provider-codex-cli`.

## Scope

- Own AI SDK provider behavior for Codex CLI app-server and exec integrations.
- Keep Agent-specific behavior generally useful when possible, but preserve Backspace-required app-server fields such as `serviceTier`.
- Do not move Agent desktop runtime, Electron IPC, app-owned `CODEX_HOME`, or bundled `@openai/codex` resolution into this package.

## Local Development

- Install dependencies with `npm install`.
- Build package output with `npm run build`.
- Validate with `npm run typecheck` and `npm run test`.
- `dist/` is generated by `tsup`; rebuild it after source changes when consuming this package through a local `file:` dependency.

## Release Notes

- The Agent app consumes this fork through `file:../../libraries/ai-sdk-provider-codex-cli` inside the Backspace workspace.
- Keep upstream remote as `upstream` and Backspace fork as `origin`.
- Do not switch Agent to a global Codex binary from this package. Agent is responsible for passing `codexPath` and environment settings.
